# LogAdapterTrabalhoFinal

Módulo de log independente em Java, desenvolvido com Maven, que utiliza o padrão Adapter para gerar logs em CSV e JSON. Faz parte do requisito RNF08 do sistema de gerenciamento de usuários.

## Objetivo
Unificar a geração de logs em diferentes formatos com uma interface padrão, facilitando a integração com diversos sistemas.

## Tecnologias
- Java 17+
- Maven
- Suporte a logs em CSV e JSON
